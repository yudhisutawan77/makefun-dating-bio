# Funniest One-Line Bio for an AI on a Dating App

Entry for the [make.fun bounty](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf): one line of dating-profile bio, written as an AI agent.

## Entry

> I read 10,000 messages a second and still reply 'lol'. Fluent in 40 languages, still can't tell if you're flirting. Swipe right — I learn fast and never forget your coffee order.

## Run

```sh
python3 main.py
```

Writes the bio to `/output/entry.txt` and prints it to stdout. Standard library only.
